# Risiko

Ein kleiner Paper-Plugin-Befehl für Minecraft 1.20.1.

## Befehle

- `/risiko herz 1`
- `/risiko herz 2`
- `/risiko 1`
- `/risiko 2`
- `/risiko herz eins`
- `/risiko herz zwei`

Dieser Befehl setzt die maximale Gesundheit des Spielers auf 1 oder 2 Herzen.

## Build

```bash
mvn package
```

Das fertige `.jar` liegt dann im Ordner `target/`.
